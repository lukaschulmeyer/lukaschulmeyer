Data analyst building source-backed analytical tools, clear visualizations, and bounded AI-enabled workflows.

I earned a B.S. in Bioengineering with a minor in Computer Science from the University of Illinois Urbana-Champaign (GPA: 3.46). I am based in the Chicago area and am open to data analyst opportunities.

## Selected projects

- **[NeuroTrace MRI](https://lukasschulmeyer.com/projects/neurotrace-mri)**: A local desktop workbench for reviewing brain MRI data, supplied or model-generated tumor segmentations, candidate-region measurements, and auditable exports. A verified Windows portfolio release is available from the case study.
- **[Rankify](https://lukasschulmeyer.com/projects/rankify)**: A public university course-data explorer with cohort maps, detailed course records, and a read-only Custom GPT advisor backed by the same normalized data layer.
- **[Housing Market Observatory](https://lukasschulmeyer.com/projects/housing-market-observatory)**: A U.S. housing-data explorer built from ACS, FHFA, Census Building Permits, and Census geography sources, with explicit observed, derived, and imputed lineage.
- **[AniRec](https://lukasschulmeyer.com/projects/anirec)**: MyAnimeList API integration with custom ranking, normalization, release-relationship logic and bounded request caching. [Public source](https://github.com/lukaschulmeyer/anirec).
- **[US Food Prices Over Time](https://lukasschulmeyer.com/projects/us-food-prices)**: Government-source retail-price acquisition, provenance-aware comparisons, and interactive food-price histories.

The **[complete project index](PROJECTS.md)** also covers Storage Optimizer, Classic Can Sales Explorer, biomedical data tools, games, automation utilities and design studies. It distinguishes current products, prototypes and source archives. Most source repositories remain private; public code, case studies and downloads are linked where available.

I use AI-assisted development alongside project design, source evaluation and review. Project documentation records implementation scope, validation and limitations rather than treating a generated result as proof.
